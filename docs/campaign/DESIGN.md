# Fifty-level campaign — approved scope change,28 October2026

The human requests roughly50 ordinary sequential levels whose difficulty rises as play continues, suitable for more advanced learners later. There is no grade picker, grade gate or grade-dependent campaign. This supersedes the original five-contract scope and any grade7/8-only product restriction in historical handoffs. Earlier user authorization to keep the finished game integrated in Workbook continues for this expansion.

Visual thesis: a warm field-journal journey through changing miniature habitats, preserving the existing rigged animals and clear fixed camera.
Content plan: one persistent level/map button; a paused chapter journal with ten five-level chapters; short chapter/tool introductions; the world remains the main play surface.
Interaction thesis: the next numbered stop opens after a genuine rescue; a restrained stamp marks completion; tool placement previews and model motion explain physical consequences. Reduced motion removes decorative transitions.

Progression: fifty authored levels, grouped ten-by-five, from preference clues to comparative sets, exclusions, ranked subsets and multi-stage rescue decisions. A changed scene/individual assignment closes each chapter. More text alone is not a difficulty increase. Later scenes must require more meaningful filtering and physical planning, with attainable solutions and distractors. Reading/help/tool planning stay paused without penalty.

Campaign rules: first useful action remains immediate; complete a level to unlock the next; completed levels can be replayed; save only local non-identifying progress; refresh resumes an eligible level. Workbook ?level=N remains a deliberate lesson-practice entry and never falsely unlocks skipped levels. A completed final direct link is not fifty completed levels. Restart retries the current level and never wipes earned progress.

Optional physical depth: a persistent distraction feeder and a temporary calming patch can help separate competing feeders without altering the usual-speed facts used by English clues. All new tools must have useful visible consequences, a simple drag/tap alternative and a keyboard equivalent. No mandatory precision aim, locomotion controls or punitive reading timer.

Art: reuse existing owned animals first; search provenance/rig evidence before adding any model. No new generation needed to fulfill the campaign. Chapters should change paths, obstacle placement, foliage/material mood and physical decisions while preserving exact visible collider correspondence and four-paw rabbit support.

Verification: independent semantic targets; per-level physical witnesses in both reflections; more than a repeated single-lure template; actual normal-input browser completion through the campaign; mistake/retry, unlock/replay/save/reload, supported direct links, late-level tools and portrait layout. Automated results establish rule/input behavior, not enjoyment or learning gains.
